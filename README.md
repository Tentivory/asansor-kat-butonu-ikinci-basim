# Asansör Kat Butonu İkinci Basım Enstitüsü

Resmi adı uzun, işlevi kısadır: ışığı zaten yanıyorken kat butonuna bir kez daha basmanın asansörü hızlandırıp hızlandırmadığını **bilimsel ciddiyetle** ölçer.

Spoiler, ama yine de ölçeriz: hızlandırmaz. Enstitü buna rağmen kapanmaz. Kapanırsa binadaki herkes merdivenle çıkar ve bu, bütçe açığından daha korkunçtur.

## Neden var

Çünkü insan, yanan ışığa güvenmez. Işık yalandır, parmak gerçektir, asansör ise 4. katta birinin çantasını düzeltmesini beklemektedir. İkinci basım bu bekleyişe karşı halk iradesidir. Halk iradesi bu binada çalışmaz. Yine de tutanak tutulur.

## Kurulum

Python 3 yeter. Bağımlılık yoktur. Asansör de yoktur. Simülasyon yeterince gerçektir.

```bash
python3 ikinci_basim.py
```

İstersen kendi katını da verebilirsin:

```bash
python3 ikinci_basim.py --kat 7 --baski 4 --ruh-hali sabirsiz
```

## Ne çıkar

- Butonun ışığının zaten yanık olduğu gerçeği
- Her fazla basış için artan bir sabırsızlık katsayısı
- Asansörün hızlanmadığına dair ıslak imzalı tutanak
- Komşunun 3. katta inip tekrar binme ihtimali
- Kuyrukta duran görünmez bir kurulun “değerlendirilecek” kararı

## Bilimsel yöntem

1. Butona bas.
2. Işık yansın.
3. Bir daha bas.
4. Işık aynı yansın.
5. Bunu evrene isyan say.
6. Çıktıyı README kadar ciddiye al.

## Lisans

Butona ikinci kez basmak serbesttir. Üçüncü basış kişisel veridir. Dördüncü basış enstitü arşivine düşer ve bir daha çıkmaz.
